# Phase 3 — Student registrations lookup endpoint (tournaments-api)

## Goal
Add ONE new key-gated endpoint to the tournaments-api edge function so the Chesster app can show "you're registered ✓" and resolve the registration id for self-cancel:

`GET /students/:student_id/registrations` — requires `x-api-key` (same `authorized()` check as register/delete).
- 401 without valid key. 400 if `:student_id` is not a UUID.
- Response: `{ "ok": true, "registrations": [{ "id": "<registration uuid>", "tournament_id": "<uuid>", "registered_at": "<iso>" }] }` — ordered by `registered_at` ascending. Empty array if none (including unknown student — no existence check needed).
- Query: `tournament_registrations` select `id, tournament_id, registered_at` where `student_id = :student_id`.
- This endpoint is key-gated because it links registrations to student identity — it must NOT be publicly readable. Do not add student_id to any existing public response.
